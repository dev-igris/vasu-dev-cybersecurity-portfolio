# Vasu Dev — Cybersecurity Portfolio

A cinematic, streaming-inspired portfolio for **Cheepuru Vasu Dev**, a B.Tech CSE (Cyber Security) student and aspiring ethical hacker. The visual identity uses a dark interface with neon-green accents.

## Run locally
Requires Node.js 18 or newer.

```bash
npm install
npm run dev
```

Open the local URL shown by Vite (usually http://localhost:5173).

To create a production build:
```bash
npm run build
npm run preview
```

## Customize content
Portfolio details live in `src/data/portfolio.ts`. The resume PDF is in `public/assets/Dev_Resume.pdf`. Replace `public/assets/cyber-avatar.svg` with a suitable image you own if you'd like a personal portrait.

Project entries are described as learning labs and should be updated as you complete more work. Do not add claims, metrics, or certifications unless they are accurate.
